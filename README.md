Projeto Windows Forms em C# para uma calculadora básica semi-científica.

Funcionalidades solicitadas:
- números de 0 até 9;
- soma, subtração, multiplicação e divisão;
- raiz quadrada;
- potência x^y;
- visor com marcador no lado direito;
- memória em variável;
- igual;
- clear;
- tela Sobre.
